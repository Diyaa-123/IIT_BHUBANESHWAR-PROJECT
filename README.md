# AI Image Search Engine Curriculum

This repository contains the Week 3–7 learning path, from a first PyTorch classifier to a deployable CLIP semantic-image-search application.

## Weekly deliverables

| Week | Topic | Deliverable |
| --- | --- | --- |
| 3 | Deep Learning Fundamentals | `week3_mlp_mnist.ipynb` — PyTorch MLP on MNIST with train/validation/test evaluation, early stopping, loss and accuracy charts, and a confusion matrix. |
| 4 | CNNs & Image Embeddings | `week4_clip_image_embeddings.ipynb` — CLIP embedding generation, dataset preview, embedding-norm histogram, PCA diagnostic, and saved index files. |
| 5 | Text Embeddings & Similarity Search | `week5_semantic_image_search.ipynb` — CLIP text embedding, cosine-similarity Top-K search, image result grid, and relevance-score chart. |
| 6 | Modular Backend | `src/`, `prepare_embeddings.py`, and `main.py`. |
| 7 | Streamlit UI | `app.py` — the Visora search experience. |

Run the notebooks from this directory so they can import the shared `src` package. Complete Week 4 before Week 5 because it builds the image index used for retrieval.

## Project structure

```text
image_search_engine/
├── week3_mlp_mnist.ipynb             # Week 3 assignment
├── week4_clip_image_embeddings.ipynb # Week 4 assignment
├── week5_semantic_image_search.ipynb # Week 5 assignment
├── data/
│   ├── images/                       # Assigned image dataset
│   └── mnist/                        # Downloaded automatically by Week 3
├── models/
│   ├── image_embeddings.npy          # Generated by Week 4
│   ├── image_paths.json              # Generated by Week 4
│   └── mnist_mlp.pt                  # Generated by Week 3
├── src/                              # Shared Week 6 backend
├── prepare_embeddings.py
├── main.py
└── app.py
```

## 1. Install dependencies

```bash
pip install -r requirements.txt
```

Open the assignments with:

```bash
jupyter notebook
```

## 2. Add the image dataset

Place the assigned images inside `data/images/`. Subfolders are supported. Use JPG, JPEG, PNG, WEBP, or BMP files.

## 3. Generate image embeddings

Use either the Week 4 notebook or this script:

```bash
python prepare_embeddings.py
```

It writes `models/image_embeddings.npy` and `models/image_paths.json`.

## 4. Run semantic search

Use either the Week 5 notebook, the CLI, or the Streamlit interface:

```bash
python main.py --query "a dog playing outside" --top_k 5
streamlit run app.py
```

## How the application works

```text
Image dataset → CLIP image encoder → Stored image embeddings
User text query → CLIP text encoder  → Cosine similarity → Top-K images
```

The model is `openai/clip-vit-base-patch32`. Hugging Face downloads it automatically on first use. Regenerate the image index whenever the dataset changes.
